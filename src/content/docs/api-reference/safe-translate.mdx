`POST /v1/medical/safe-translate` behaves identically to `/translate` but **automatically withholds the translation** when risk exceeds the safe threshold (`"high"` or `"critical"`).

For the full schema, see the [Interactive Reference](/api-reference/).

---

## Withheld response shape

Withholding fires whenever `risk` comes out `"high"` or `"critical"`. When it does, `translation` and `back_translation` are `null`, `verified` is `false`, and two extra fields explain what happened and what to do next — there is no `withheld` field, `translation === null` **is** the signal:

```json
{
  "translation": null,
  "back_translation": null,
  "confidence": 0.48,
  "risk": "critical",
  "flags": [{ "type": "negation_flip", "detail": "…", "severity": "critical" }],
  "suggestion": "Please rephrase using simpler language",
  "reason_class": "critical_flag",
  "escalation_options": [
    { "type": "human_interpreter_dispatch", "label": "Request a human interpreter" },
    { "type": "clinician_acknowledgment", "label": "Clinician acknowledges risk and proceeds" }
  ],
  "verified": false,
  "metadata": { ... }
}
```

This is a `200` response — not an error. Your UI must check `translation === null` (or `!verified`) before rendering `translation`. See [Understanding the Response](/getting-started/understanding-the-response/#reason_class--string-present-only-on-refusals) for the full `reason_class`/`escalation_options` reference.

---

## Safe response shape

When the translation passes safety checks:

```json
{
  "translation": "Do you take any blood-thinning medication?",
  "back_translation": "Tar du blodfortynnende medisiner?",
  "confidence": 0.93,
  "risk": "low",
  "flags": [],
  "verified": true,
  "metadata": { ... }
}
```

## Handling withheld translations in your UI

<Tabs>
<TabItem label="cURL">
```bash
curl -X POST https://api.tolka.health/v1/medical/safe-translate \
  -H "Authorization: Bearer sk_test_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Tar pasienten blodfortynnende?",
    "source_language": "no",
    "target_language": "en",
    "mode": "safe",
    "context": { "domain": "gp" }
  }'
```
</TabItem>
<TabItem label="TypeScript">
```typescript
const result = await tolka.safeTranslate({
  text: sourceText,
  source_language: 'so',
  target_language: 'no',
  mode: 'safe',
  context: { domain: 'emergency' },
});

if (result.translation === null) {
  // Translation is NOT safe to display — result.reason_class explains why
  return (
    <RefusalAlert
      flags={result.flags}
      escalationOptions={result.escalation_options}
      message="The translation quality could not be verified. Use a professional interpreter."
    />
  );
}

// Safe to display
return <TranslationDisplay text={result.translation} risk={result.risk} />;
```
</TabItem>
<TabItem label="Python">
```python
import requests

response = requests.post(
    "https://api.tolka.health/v1/medical/safe-translate",
    headers={"Authorization": "Bearer sk_test_YOUR_KEY_HERE"},
    json={
        "text": "Tar pasienten blodfortynnende?",
        "source_language": "no",
        "target_language": "en",
        "mode": "safe",
        "context": {"domain": "gp"},
    },
)
data = response.json()

if data["translation"] is None:
    print(f"Translation withheld ({data.get('reason_class')}) — flags: {data['flags']}")
else:
    print(data["translation"])
```
</TabItem>
</Tabs>
