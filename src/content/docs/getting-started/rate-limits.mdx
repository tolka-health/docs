## Per-plan limits

| Plan | Requests/minute | Requests/month | Burst |
|------|----------------|----------------|-------|
| Sandbox (shared) | 10 / IP | 50 / IP / day | No burst |
| Community | 20 | 200 | 40 for 10s |
| Starter | 60 | 500 | 120 for 10s |
| Pro | 300 | 5,000 | 600 for 10s |
| Enterprise | Custom | Unlimited | Negotiated |
| Emergency | 500 | Unlimited | 1,000 for 10s |

## Rate limit headers

Every response includes these headers:

| Header | Description |
|--------|-------------|
| `X-RateLimit-Limit` | Your plan's requests-per-minute ceiling |
| `X-RateLimit-Remaining` | Requests remaining in the current minute window |
| `X-RateLimit-Reset` | Unix timestamp when the window resets |
| `Retry-After` | Seconds to wait before retrying (present only on `429` responses) |

```http
HTTP/2 200
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 43
X-RateLimit-Reset: 1744375260
```

## Handling 429 responses

When you exceed your limit, the API returns `429 rate_limited`:

```json
{
  "error_code": "rate_limited",
  "message": "Rate limit exceeded"
}
```

The wait time is in the `Retry-After` response header (seconds), not the JSON body. **Always read it from the header** — do not hardcode wait times.

:::note[Header not exposed on `TolkaApiError`]
The current SDK doesn't surface `Retry-After` as a typed field — it only captures `X-Request-Id`. Fall back to exponential backoff, or read the header yourself if you're calling the HTTP API directly rather than through the SDK.
:::

<TabItem label="TypeScript">
```typescript
async function translateWithRetry(
  client: TolkaClient,
  params: TranslateParams,
  maxRetries = 3,
): Promise<TranslateResponse> {
  for (let attempt = 0; attempt <= maxRetries; attempt++) {
    try {
      return await client.translate(params);
    } catch (err) {
      if (err instanceof TolkaApiError && err.errorCode === 'rate_limited') {
        const wait = Math.min(1000 * Math.pow(2, attempt) + Math.random() * 500, 30_000);
        if (attempt < maxRetries) await new Promise((r) => setTimeout(r, wait));
        else throw err;
      } else {
        throw err;
      }
    }
  }
  throw new Error('unreachable');
}
```

import time, random

def translate_with_retry(client, params, max_retries=3):
    for attempt in range(max_retries + 1):
        try:
            return client.translate(**params)
        except TolkaApiError as e:
            if e.error_code == "rate_limited" and attempt < max_retries:
                wait = min(2 ** attempt + random.random(), 30)
                time.sleep(wait)
            else:
                raise
